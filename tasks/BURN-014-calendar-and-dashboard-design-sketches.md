## First principle

A layout mistake takes minutes to fix in a sketch and hours to fix in code. A sketch also shows whether the screens answer the user stories before anything is built.

## What fails without this task

We build screens, argue about them, and rebuild them.

## Description

Wireframe the area selection, the year-by-month calendar, the anomaly view and the export. Choose the color ramps.

## Acceptance criteria

- [ ] Wireframes exist for the four screens
- [ ] A sequential ramp is chosen for activity and a diverging ramp for anomalies
- [ ] Both ramps are checked with a color-vision-deficiency simulator
- [ ] Values can be read without relying on color (numbers or tooltips)
