## First principle

A project is judged only if the team behind it is eligible. Eligibility is settled by registration, which no amount of building can repair after the deadline.

## What fails without this task

A waitlisted registration makes the project ineligible for Global Judging, and without a team page there is no Project tab to submit from.

## Description

This entry is one person at the Guelph Local Event. Confirm on the Space Apps site that the registration is confirmed and that a team of one exists with this challenge selected. This is registration, so it can be done before the hackathon starts.

## Acceptance criteria

- [x] The participant is registered for the 2026 event at the Guelph Local Event
- [x] The Guelph event page shows the registration as confirmed, not waitlisted
- [x] A team exists under "My Team" with the participant as Team Owner
- [x] The team has selected "Harmonization of MODIS and VIIRS Hot Spots" as its challenge
- [x] The Local Event's time zone is written in `docs/rules.md`, with the deadline in that zone
- [x] The Guelph schedule has been checked for a live pitch, and none is listed
- [x] The participant is not taking part in connection with a China-affiliated entity, as defined in the Terms and Conditions
