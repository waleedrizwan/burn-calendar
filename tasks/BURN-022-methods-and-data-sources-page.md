## First principle

Trust comes from being able to check the method. A result with no explanation asks the user for faith.

## What fails without this task

The numbers are published without the explanation that lets anyone believe them.

## Description

Write a page in the app that explains the harmonization, its limits and its data sources.

## Acceptance criteria

- [ ] The harmonization is explained in plain language
- [ ] Limitations are listed, including that a hotspot detection is not a fire
- [ ] Validation results from BURN-008 are summarized
- [ ] Data sources are cited as FIRMS requires
- [ ] The page is linked from the app
